CUDA 二十年

CUDA 不只是一个编程模型，它是一个用 二十年建起的飞轮。安装基数越大，优化越多；优化越多，成本越低；成本越低，用户越多。这个正反馈循环让 NVIDIA 的加速计算平台从图形渲染扩展到了科学计算、AI、机器人——几乎每一个计算密集型领域。

数据处理加速

Token 工厂经济学

AI 工厂的核心指标是 tokens per watt——每瓦电力能产出多少 token。Blackwell NVLink72 系统配合 Dynamo 推理引擎，让 NVIDIA 的单 token 成本成为全球最低。通过 NVFP4 精度格式和极限代码设计，同一套硬件的吞吐量不断提升。

Vera Rubin

Vera Rubin 是 NVIDIA 为 Agent AI 时代设计的下一代系统。NVLink 从 72 芯片扩展到 144，集成 Groq LPX 实现解聚推理——prefill 和 decode 分别在最适合的芯片上运行。路线图一路延伸到 Feynman，每一代都在 tokens/watt 上实现数量级提升。
