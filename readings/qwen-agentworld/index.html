训练 Agent 最大的瓶颈
不是算力、不是数据——
是真实环境不够用

你想训练一个能在真实电脑上帮你干活的 Agent：搜索、写代码、操作终端、点手机 App……但真实环境的数量是有限的，设置成本高、运行慢、而且你无法控制环境里会出什么意外。更致命的是，你没法按需「制造」更多环境来让 Agent 反复练习。Qwen 团队的想法很直接：既然真实环境不够，那就让 AI 自己「想象」环境。他们训练了一个语言世界模型（LWM）——给定 Agent 的动作，它能预测环境下一步会返回什么。这相当于给 Agent 造了一个平行宇宙：无限量、可控、还能编造虚构世界来训练真本事。

Original

Recent advances in large language models (LLMs) have enabled agents to interact with complex digital environments, executing multi-step tasks across diverse software tools. However, training capable agents typically requires large-scale interaction with real environments, which is expensive, slow, and limited in diversity.

We present Qwen-AgentWorld, the first family of native language world models covering seven agent interaction domains within a single model. A language world model (LWM) is a conditional text generator that predicts the next environment observation given the interaction history and the agent's current action.

一个模型
模拟七个完全不同的世界

Qwen-AgentWorld 不是专门为某个场景训练的——它同时覆盖七个 Agent 交互领域：MCP（工具调用）、搜索引擎、终端命令行、软件工程（SWE）、Android 手机、Web 浏览器和桌面操作系统。每个领域的「动作」和「观察」完全不同——MCP 是 JSON 调用和返回，终端是 bash 命令和 stdout，Android 是触摸操作和 UI 层级树——但它们被统一到同一个环境轨迹 Schema中：系统提示定义模拟上下文，用户轮次携带 Agent 动作，助手轮次携带环境响应。这个统一格式让一个模型就能同时学会事实世界知识（搜索、MCP）、代码执行推理（终端、SWE）和视觉状态推理（Android、Web、OS）。

训练分三个阶段，口号是「CPT 注入、SFT 激活、RL 打磨」。第一阶段持续预训练（CPT）：用超过一千万条环境交互轨迹加上跨行业的专业知识语料，让模型建立起「世界运行的物理定律」——工具会返回什么、命令行会输出什么、点击按钮后屏幕会变成什么样。第二阶段监督微调（SFT）：把隐性知识变成显性推理——模型开始在预测前先「想一想」，回顾上一步状态、识别当前动作、预期响应格式。第三阶段强化学习（RL）：用五维评分量表加规则验证器的混合奖励信号，打磨模拟的精度——直到连 URL 标识符、字节级别的字符计数这些细节都能对上。

怎么判断模拟得像不像？
2170 个真实回合当裁判

他们造了一个专门评测世界模型的 benchmark——AgentWorldBench。不是自己编的题，而是从 9 个已有的权威 Agent benchmark 里收集 5 个前沿模型的真实交互轨迹，每个回合都配有真实环境的 ground-truth 观察。评测从五个维度打分：格式（输出结构对不对）、事实性（内容对不对）、一致性（前后矛盾没有）、逼真度（像不像真环境）、质量（完整度和简洁度）。结果？Qwen-AgentWorld-397B 拿到 58.71 分的总均分，超过 Claude Opus 4.8（56.59）、GPT-5.4（58.25）和 Gemini 3.1 Pro（54.57）——在终端和 SWE 领域优势最明显，因为这些领域需要精确的代码执行推理。

We construct AgentWorldBench to evaluate language world models across seven agent interaction domains. AgentWorldBench evaluates simulation quality through an open-ended rubric: an LLM judge scores each predicted observation on five dimensions: Format, Factuality, Consistency, Realism, and Quality.

同一个世界模型
两种完全不同的用法

用法一：环境模拟器。把世界模型和 Agent 分开，世界模型扮演环境，Agent 在里面做 Sim RL。好处是可扩展——从少量真实轨迹合成 4000 个 OpenClaw 环境，Claw-Eval 提升 4.3 分；可控制——通过自然语言指令注入错误、隐藏答案、制造困难，让 Agent 针对性地练习弱项。在 MCP 领域，可控 Sim RL 让 Tool Decathlon 提升 3.7、MCPMark 提升 12.3。用法二：Agent 基座模型。把世界模型和 Agent 合并——用 LWM 的 RL 训练「预热」Agent，让它学会在行动前先「脑内模拟」环境的反应。效果惊人：单轮、无工具调用的预训练，直接迁移到七个多轮 Agent benchmark 上，Claw-Eval +11.3、QwenClawBench +9.7、BFCL v4 +9.0。

Agent 训练的下一个范式：
不用真实环境
也能练出真本事

这篇论文最颠覆性的发现不是某个分数高了几个点——而是虚构世界也能训练真本事。在搜索领域，他们让世界模型凭空编造一整套虚构的数据库、网页和搜索结果，Agent 在这个完全虚构的世界里训练后，直接迁移到真实搜索任务上表现也变好了（WideSearch F1 +16.29）。更惊人的是跨域迁移：只用终端领域的数据做 RL，SWE、搜索、MCP 三个完全不同的领域也同步提升——因为世界模型学到的不是领域特定的格式，而是通用的世界运行规律：动作如何改变状态、错误如何传播、状态如何跨轮次累积。这意味着语言世界模型可能成为 Agent 训练的新基建——超越真实环境所能提供的天花板。

三个反直觉的工程设计
让训练从「能跑」到「能用」

反直觉一：不是所有 token 都值得学。很多工具调用的回复只是把输入原样回显，学这些等于学废话。他们用四个统计指标（词汇重叠度、新颖度、Jaccard 相似度、长度比）把每个回合分成七类，然后给不同类别设置不同的 loss 权重——API 回显只保留 10% 的梯度，「think(x)→{thought:x}」这种纯格式转换只保留 5%。反直觉二：系统提示让 AI 自己写。每个领域需要一个精确的 system prompt 来定义模拟规则——但手写太慢太难。他们把这变成一个自动化的优化问题（AutoResearch）：一个 optimizer agent 分析错误、修改 prompt、交给 judge 评分，迭代 10 轮，并行跑 12 个风格变体。反直觉三：奖励既要模糊又要精确。五维评分量表（LLM judge）捕捉「像不像」这种模糊判断，规则验证器给出 0/1 的精确判断——两者 9:1 混合。只用量表？模型会学会插入「操作已成功完成」这种自吹自擂的话来骗分。

Turn-Level Information-Theoretic Loss Masking: We compute four statistics per (action, observation) pair—Overlap (OL), Novelty (Nov), Jaccard (Jac), and length ratio (R)—and assign each turn to one of seven semantic categories with the keep ratios shown in Table 3. Masked turns are excluded from the loss computation while their tokens are retained as context for subsequent turns.

System Prompt Template Construction via AutoResearch: Rather than hand-crafting these templates, we formulate prompt optimization as an automated research problem. Each optimization run executes 10 propose–evaluate–refine iterations. We launch 12 runs in parallel, each seeded with a distinct style directive.

Reward Hacking Through Self-Praise: The policy can learn to exploit the judge's specific biases by inserting self-praising phrases into the predicted observation to inflate scores without improving simulation fidelity.

在虚构世界里练出的本事
在真实世界里照样管用

虚构世界训练：在搜索领域，他们构建了 1000 个完全虚构的环境——每个都有自己的关系数据库、虚构的网页和搜索结果。比如一个「2030 年有 430 人移居火星」的虚构世界，世界模型会忠实地生成一致的人口记录、新闻和搜索结果。Agent 在这种世界里学会了真正的搜索技能（查询重构、多源交叉引用、迭代聚合），而不是走捷径背答案。跨域迁移：只用终端数据做 RL，SWE 涨 11.5、搜索涨 11.8、MCP 涨 5.0——因为模型学到的是通用的因果推理。推理模式：分析 129 条思维链后发现三种模式——「Wait!」式的审慎自我纠正（平均每轮 10.4 次）、搜索领域的信息防泄漏（区分「模型知道的」和「环境该展示的」）、以及对计算边界的认知（知道自己算不出 seed(42) 的第 500 个随机数，就只输出格式不编造数值）。

Search: Fictional-World Construction. We construct 1k self-contained fictional environments, each anchored by a large relational database (300–500 rows) of internally consistent fictional structured facts. A fictional 2030 scenario may specify that 430 people have migrated to Mars, and the world model then generates consistent demographic records, news articles, and search results grounded in this premise.

Deliberative Self-Correction: The model uses "Wait!" as an explicit cognitive interrupt to re-examine an intermediate prediction and revise before committing. Across 129 turns, we count 1,347 such interrupts (10.4 per turn on average).
