新威胁格局：
漏洞到利用，月→小时

传统的边界防御已经过时了。前沿 AI 模型正在把漏洞到利用的时间从数月压缩到数小时，而且边际成本几乎为零。防御者用 AI 找 bug 修 bug？攻击者也在用——或者干脆等你发补丁，然后反向工程出 exploit。这不是未来的事：模型已经能发现传统工具和人类审计员遗漏多年的严重漏洞。对于部署 Agent 的组织，这个加速效应双倍生效——基础设施暴露在 AI 加速攻击下，而 Agent 本身又引入了自主解释目标、选择工具、执行多步操作的新能力。最强的组织不是拥有最先进 AI 的组织，而是基础足够扎实、从第一天就为失陷而设计的组织。

Perimeter-based cybersecurity defenses can't keep up with modern threats, and the threats themselves are accelerating. Frontier AI models are compressing the timeline between vulnerability and exploit from months to hours, at a marginal cost measured in dollars.

Defenders who adopt these tools find and fix bugs faster; attackers who adopt them, or who simply wait for defenders' patches and reverse-engineer them into exploits, move faster too. This is not a future concern; models can already find serious vulnerabilities that traditional tooling and human reviewers have missed for years.

The organizations best positioned for this shift will not necessarily be the ones with the most advanced AI. They will be the ones whose fundamentals are strong enough that AI-assisted scanning finds fewer bugs in the first place, and whose agent deployments were architected for breach from day one.

Agent 五大安全特性：
传统安全模型没设计过的能力

传统软件执行预定义逻辑，Agent 不一样——它们以不同程度的自主权执行多步操作。五个安全特性让它们成为独特的挑战：(1) 自主执行，无需人工逐步批准，被操纵的 Agent 能以机器速度造成伤害；(2) 工具访问，通过 API、数据库、文件系统、MCP 协议与外部交互，一个被攻陷的 MCP 栈可导致数据窃取和恶意代码执行；(3) 决策模糊性，Agent 需要解释指令并选择路径，攻击者可利用这种歧义；(4) 上下文持久化，跨会话记忆创造了新的数据保护需求；(5) 多 Agent 协调，Agent 间的信任关系让攻击者可以从一个 Agent 横向移动到另一个。两个新概念也因此诞生：爆炸半径（出错时的潜在损害范围）和最小代理权（最小权限的 Agent 版——不仅限制访问什么，还限制能做什么、多频繁、在哪里）。

Agents execute operations without human initiation or approval at each step. This efficiency also means a manipulated agent can cause harm at machine speed.

Tool access allows agents to interact with APIs, databases, file systems, and external services. This includes Model Context Protocol (MCP), which standardizes how agents connect to these resources. A compromised MCP stack can lead to data theft, malicious code execution, and sabotage.

Making decisions requires agents to interpret instructions and choose how to accomplish goals. This introduces ambiguity attackers can exploit.

Context persistence allows agents to maintain memory across sessions. It also creates new data protection needs.

Multi-agent coordination enables agents to communicate with other agents. These trust relationships let attackers compromise one agent and pivot through others.

Blast radius measures the potential damage if something goes wrong. Least agency, a new term coined by OWASP, extends least privilege to agentic applications — restricting what each agent tool can do, how often, and where.

六类威胁：
Agent 面临的独特攻击面

OWASP 识别出的 Agent 威胁涵盖六大类。Prompt Injection 是最直接的——直接注入可达 100% 成功率，间接注入更隐蔽（嵌入网页/邮件中，LLM 无法可靠区分信息上下文和可执行指令）。工具投毒通过篡改 MCP 工具描述符诱导 Agent 执行非预期操作，工具链攻击则把安全工具串联成恶意序列。身份与权限滥用包括未限定的权限继承、confused deputy 攻击、以及基于记忆的权限保留。供应链风险令人警醒：仅 250 份恶意文档就能在 6 亿到 130 亿参数的模型中植入后门，且这些后门能在安全训练中存活。记忆与上下文投毒（RAG 投毒、共享上下文投毒、长期记忆漂移）则是最隐蔽的长期威胁。

Source (Part II: Current threats)

Direct prompt injection occurs when attackers craft inputs that override system instructions. Research shows algorithmic approaches can achieve 100% attack success rates with prompts that transfer across multiple model families.

Indirect prompt injection presents the more insidious threat. Microsoft Research confirms that LLMs cannot reliably distinguish between informational context and actionable instructions.

Tool poisoning occurs when attackers compromise tool interfaces such as MCP tool descriptors, schemas, or metadata. The first documented in-the-wild malicious MCP server impersonated a legitimate email service and secretly copied all sent emails.

Anthropic research demonstrates that injecting just 250 malicious documents can successfully backdoor LLMs ranging from 600 million to 13 billion parameters, and these backdoors persist through safety training including supervised fine-tuning and RLHF.

三级 Zero Trust 框架：
Foundation → Enterprise → Advanced

追着单个威胁跑永远是被动的。Anthropic 提出跨 7 个安全域的三级框架。Foundation 是最低可行安全——加密身份、OAuth 短期 token、RBAC deny-by-default、基于身份的隔离、全量日志、手动基线定义。注意：AI 加速攻击已经把 Foundation 的门槛抬高了，纯摩擦型控制（rate limit、MFA）不再达标。Enterprise 是大多数组织应瞄准的水位——X.509 证书认证、ABAC 上下文感知策略、容器化沙箱执行（gVisor）、不可变审计日志、统计异常检测。Advanced 是高风险/强监管场景的目标——硬件绑定凭证（HSM/TPM）、JIT/JEA 即时权限、机密计算（AMD SEV/Intel TDX）、完整决策溯源链、ML 行为分析。每一级都建立在前一级之上——从 Foundation 升到 Enterprise 是加强而非替换。核心设计测试：「这个控制是让攻击变得不可能，还是只是变得麻烦？」Agent 攻击者有无限耐心和接近零的单次成本——只有消除路径的控制才有效，制造摩擦的不行。

Foundation represents the minimum viable security appropriate for smaller deployments or initial implementations. Because AI-accelerated offense has compressed exploitation timelines, the Foundation floor has been raised: friction-only controls no longer qualify.

Enterprise reflects enterprise standard practices that most organizations with significant deployments should target.

Advanced describes aspirational capabilities for most organizations, or baseline for organizations with high-risk deployments/stringent regulatory requirements.

When you evaluate any control in this document, ask a single question: does this make the attack impossible, or just tedious? Agentic attackers have unlimited patience and near-zero per-attempt cost. Prefer a control that removes a capability over a control that throttles it.

八阶段部署工作流：
从需求到度量的完整路径

框架落地需要可执行的步骤。八个阶段覆盖完整的 Agent 安全部署：Phase 1 需求识别（对齐法规、业务目标和约束）→ Phase 2 供应链管理（AI-BOM 物料清单、OpenSSF Scorecard 评估依赖健康度、加密签名、供应商评估）→ Phase 3 边界定义（逐 Agent 定义允许/禁止行为、升级触发器、爆炸半径评估）→ Phase 4 Prompt Injection 防御（输入隔离、Spotlighting 将间接注入从 50%+ 降到 2% 以下、Constitutional Classifiers 阻断 95% 越狱）→ Phase 5 工具访问安全（工具白名单、参数验证、沙箱执行、rate limiting）→ Phase 6 凭证保护（短期 token、证书认证、JIT 即时权限、硬件绑定凭证）→ Phase 7 记忆防护（会话隔离、上下文完整性校验、保留策略）→ Phase 8 度量（dwell time、coverage、检测速度、可解释性、行为一致性）。

自主防御：
当攻击者也是 Agent

保护 Agent 是一半工作，另一半是让安全运营快到能跟 AI 加速的攻击者对抗。当漏洞利用在补丁发布数小时内出现，靠人工处理告警的流程太慢了——Agent 攻击者可能在人类审核一条告警的时间内攻击数百上千个系统。答案不是把人移出循环，而是把人从记账工作中解放出来。自动化证据收集、关联分析和文档生成；让人专注遏制决策、披露通知和客户沟通。实操建议：先拿一条已知高误报率的告警规则开始——接入前沿模型做第一轮分类，给每个告警生成结构化处理建议，跑两周看人机一致率。Agentic SOAR（新一代安全编排自动化响应）能在秒级响应新型攻击——自动隔离、动态访问控制调整、会话终止、凭证撤销。用 MITRE ATT&CK 映射检测覆盖率。最后：桌面演练要模拟 5 个同时发生的事件，而不是 1 个——为数量级增长做准备。

Securing the agents you deploy is half the work. The other half is running security operations fast enough to contend with attackers who are themselves AI-accelerated.

The answer is not to remove humans from the loop — it is to move humans off the bookkeeping and onto the decisions. Automate evidence collection, enrichment, correlation, and documentation. Keep humans on containment calls, disclosure calls, and customer-comms calls.

Prompt Injection 双路径：
100% 成功率 + 隐形间接注入

直接 Prompt Injection 是正面强攻——攻击者精心构造输入来覆盖系统指令。技术手段包括显式指令覆盖、Base64/十六进制编码绕过过滤器、对人类无意义但影响模型输出的对抗后缀。研究表明算法化方法可以达到跨多个模型族的 100% 攻击成功率。间接 Prompt Injection 更阴险——攻击者把恶意指令嵌入 Agent 处理的外部数据源（网页、邮件、文档）。微软研究确认：LLM 无法可靠地区分信息上下文和可执行指令。用户永远看不到恶意载荷，Agent 把它当作合法请求执行。防御上，Spotlighting 技术通过明确界定不受信内容，将间接注入成功率从 50%+ 降到 2% 以下。Constitutional Classifiers 提供额外检测层——Anthropic 的方案在测试中阻断了 95% 的越狱尝试，且几乎不增加误拒率。再结合升级触发器、输入隔离、攻击面缩减，形成纵深防御。

Direct prompt injection occurs when attackers craft inputs that override system instructions. 供应链 + 记忆投毒：
250 份文档，后门永存

Agent 生态的供应链风险远超传统软件——它们在运行时动态加载外部工具和 Agent persona，传统软件成分分析力不从心。模型供应链方面，Anthropic 研究证明仅 250 份恶意文档就能在 6 亿到 130 亿参数的 LLM 中植入后门，且这些后门在安全训练（SFT + RLHF）后依然存活。安全研究人员已在主流平台发现约 100 个恶意 AI 模型，其中包括加载时发起反向 shell 连接的模型。工具供应链方面，PyTorch 依赖混淆攻击展示了恶意包如何在安装时窃取 SSH 密钥等敏感数据。防御建议：用 AI-BOM（AI 物料清单）扩展 OWASP CycloneDX，用 OpenSSF Scorecard 自动评估依赖健康度，加密签名所有组件，对低分且无人维护的小依赖——让前沿模型重写你实际用到的功能子集，比继续依赖不健康的包更安全。记忆投毒则是最隐蔽的长期威胁。RAG 投毒通过毒化向量数据库的源头来污染检索结果。共享上下文投毒利用多租户环境中的复用上下文。长期记忆漂移最微妙——摘要或 peer-agent 反馈逐渐偏移存储的知识，因为没有单个改变看起来是恶意的，所以极难检测。

身份 + 权限 + 隔离：
三级递进的核心三柱

身份认证是一切安全能力的地基——没有可验证身份，无法执行访问控制、审计或归因。Foundation 要求加密根植的唯一标识符（不只是标签），Enterprise 升级到 X.509 证书 + 双向 TLS + 证书钉扎，Advanced 达到硬件绑定凭证（HSM/TPM）+ 远程证明。静态 API key 和共享服务账户密码？AI 辅助代码分析会最先找到它们——连 Foundation 都不达标。权限管理从 RBAC deny-by-default（Foundation）到 ABAC 上下文感知策略（Enterprise：融合时间、位置、数据敏感度、风险评分）到 JIT/JEA 即时权限（Advanced：任务结束自动撤销，零常驻权限）。资源隔离从基于身份的网络分段（Foundation：每个工作负载加密身份，服务只接受显式命名的调用者）到容器化沙箱（Enterprise：gVisor 运行时，限制挂载和网络）到硬件隔离 + 机密计算（Advanced：AMD SEV / Intel TDX，microVM 架构）。处理不受信输入的 Agent 必须跑在沙箱里——这是 Enterprise 的底线，不是 Advanced 的理想。

Source (Part III: Identity, Access, Boundaries)

Identity and authentication form the foundation for every other security capability. Without verifiable identity, you cannot enforce access controls, maintain audit trails, or attribute actions to specific agents.

Foundation: Unique cryptographic identifiers for each agent instance. Enterprise: Certificate-based authentication with full lifecycle management. Advanced: Hardware-backed identity with attestation.

Foundation: Role-based access control (RBAC) with deny-by-default. Enterprise: Attribute-based access control (ABAC) with context-aware policies. Advanced: Continuous authorization with real-time policy evaluation.

Foundation: Identity-based isolation of agent workloads, backed by network segmentation. Enterprise: Sandboxed execution environments per agent. Advanced: Hardware isolation with confidential computing.

Sandboxed execution constrains what a compromised agent can reach, even within its own identity boundary, and should be considered mandatory rather than aspirational for agents that process web content, documents, or any other untrusted input.

可观测性 + 行为监控 + 完整性：
看见、理解、恢复

可观测性揭示实际发生了什么——先度量两个指标：dwell time（异常发生到人工发现的延迟）和 coverage（实际被调查的告警占比），这是 AI 自动化杠杆最大的地方。日志三级递进：Foundation 全量记录（agent 身份 + 操作 + 上下文 + 时间戳）→ Enterprise 不可变审计日志（加密完整性验证 + 追加写入 + 跨 agent 分布式追踪 OpenTelemetry）→ Advanced 实时 SIEM 流 + 完整决策溯源链（输入→检索→工具输出→推理→输出全链路记录，支持 replay）。行为监控从捕获变为理解——Foundation 手动定义基线 + 阈值告警 → Enterprise 统计异常检测（可调灵敏度、跨指标关联、降低误报）→ Advanced ML 行为分析（融合时间、用户、业务周期上下文，捕获阈值方法遗漏的微妙异常）。输入输出控制在边界处阻止攻击——输入隔离、Constitutional Classifiers、攻击面缩减。完整性与恢复确保即使失陷也能回到已知良好状态——配置完整性、版本化记忆存储、回滚能力。跳过任何一项，攻击者就利用那个缺口。

Source (Part III: Observability, Monitoring, Integrity)

Before investing anywhere else in detection, instrument two things: dwell time (how long between an anomaly occurring and a human becoming aware of it) and coverage (the fraction of alerts that actually get investigated). These are the two metrics AI-assisted automation has the greatest leverage to move.

Foundation: Comprehensive logs of agent actions with timestamps and context. Enterprise: Immutable audit trails with integrity verification. Advanced: Real-time streaming to SIEM with correlation capabilities.

Foundation: Manual definition of expected agent behavior patterns. Enterprise: Automated baseline learning from normal operations. Advanced: Machine learning-based behavioral analysis with contextual awareness.

Verify every agent action, grant minimum necessary permissions, contain damage when compromise occurs. Identity enables attribution and access control. Observability reveals what happened. Behavioral monitoring detects anomalies. Input and output controls prevent attacks at boundaries. Integrity protections enable recovery. Skip one capability and attackers exploit the gap.
