Agent 新计算范式：
脑 + 身体 + 工具 = 新应用

过去的应用是代码跑在操作系统上。现在的应用是 Agent——大模型是「大脑」，harness（编排框架）是「身体」，工具是「工作间」。每次 Agent 思考，就激活一整个 Grace Blackwell NVLink 72 机架；每次使用工具，就调用 CPU 或加速计算。Agent 是史上最分布式、异构化的计算模型——模型、编排、工具、安全、存储分布在数据中心的不同位置。NVIDIA 的 1000+ CUDA-X 库现在都配备了「技能手册」，让 Agent 能像老手一样调用 cuLitho（光刻计算）、cuOpt（决策优化）、PhysicsNeMo（可微物理）等工具。「Agent 比人类还不耐烦——它们活在纳秒级的世界里」。这种全新的计算模式，正是 Vera Rubin 诞生的原因。

Vera CPU：
为 Agent 而生的处理器
