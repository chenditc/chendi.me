Act I

三次赴死

01 — 三次赴死

高中做浏览器赚了 30 万美金，然后花了六年训模型、做搜索引擎——直到 GPT-3 随便一个 prompt 就和他五五开。「天要塌了。」

季逸超（Peak）4 岁去美国，二年级回国，高中时做了 iOS 浏览器「猛犸」，靠 App Store 付费下载赚了第一桶金。真格基金承诺「不管干什么都投」，他用这笔钱从零搭了搜索引擎、爬虫、索引，训了两个 0.3B 模型解决 16K long context——产品叫 Magi。但移动互联网的蛮荒期靠的是硬件平台更替，AI 时代没有新平台，所有人的反应速度一样快。2019 年拿到 GPT-3 early access 的那个下午，他发现通用模型正在吃掉一切垂直解——「我的第一反应就是赶紧卖掉公司。」

02 — 正常人联盟

「别的创始人都太艺术家了。」他找了一个身心健全、没有极端思想的 CEO——这在 AI 圈已经是稀缺品质。

卖掉 Magi 后，Peak 聊遍了所有大模型公司，但上次创业的 PTSD 让他不想再碰垂直整合。他需要一块「空的画布」来观察用户。Chrome 插件 Monica 就是这块画布——它不改变用户习惯，功能分发基于 context，消解了复杂度爆炸。而 Monica 的创始人肖红最稀缺的品质是「很正常」：身心健全，没有不良嗜好。Peak 意识到 AI 时代更像制造业——用户量增长，成本线性提升，对经营能力的要求远高于移动互联网。最终，所有大模型公司都会变成模型+应用公司，而做出好应用比做出好模型难得多。

ACT II

手的觉醒

03 — 浏览器之死

「当你觉得一款产品不酷的时候，就别发。你都觉得不酷，没人会觉得酷。」然后他们放弃了做了四个月的 AI 浏览器。

AI 浏览器有三个致命问题：端侧模型追求离线但浏览器本身联网；AI 接管用户电脑就像「两个人抢一台电脑」；长任务需要电脑一直开着。Arc 浏览器创始人宣布放弃验证了他们的判断。放弃后两周半的「无所事事」孕育了真正的 idea：公司非工程师在用 Cursor 写博客、做数据分析——编程不是垂直能力，而是通用能力。把 AI 浏览器搬到云端，代码作为工具而非主要呈现，面向 Prosumers 而非程序员。项目代号 Airbnb——Browser in the air。MIT 校训 Mens et Manus（心与手），别人做心智，他们要做那只手。

04 — 三个 Bet

Monica 是生鱼片——原材料好就行。Manus 是水煮鱼——厚壳才是价值所在。

第一个 Bet：相信通用 Agent 能被制造出来。第二个：不训模型，信赖 context engineering。第三个：不做中国版 Cursor，面向 prosumers 做差异化。Agent 与 Chatbot 的根本区别在于第三个元素——环境。每个 Manus 会话背后是独立的 Firecracker 虚拟机沙盒，为 Agent 设计了专门的 Linux 发行版。通用 Agent 真正的价值在长尾——「Google 之所以赢，是因为永远能在长尾 query 中给你惊喜。」Manus 本质上是一款个人云计算产品——让不会编程的人也能操作云计算。

05 — 灵魂冲突

所有大模型都在为 Chatbot 做对齐——但 Agent 的工况和 Chatbot 完全不同。这是当前最被忽视的矛盾。

Chatbot 的 input:output 比是 3:1，Agent 是 100:1 到 1000:1。模型被训练成「一次回答完毕」，但 Agent 需要基于 ReAct 逐步尝试。200K 以上的 context 不重要，更重要的是让模型学会 compression awareness。Interleaved thinking 优于纯脑内 reasoning。应用公司做综合，模型公司做垂直——这个反直觉的分工正在发生。Manus 用不同场景的最佳模型组合：Anthropic 做 coding、Gemini 做多模态、OpenAI 做 reasoning。「好像全世界都在帮我们一起训模型。」

ACT III

纯血与克制

06 — 发布风暴

「世界上能够在第二天立即到位的算力比想象中少太多了。」上线第一天烧几十万美金，Anthropic 说：千万别放开，你放开我们会挂。

邀请码不是饥饿营销——云厂商和模型厂商的算力完全没准备好 Agent 级别的消耗。GCP「物理层面去搬卡插在机柜上」才解了燃眉之急。Manus 追求的不是 DAU 而是营收，高价值用户问的是「能不能付 200 美金让效果更好？」。a16z 数据：装了所有 Chatbot 的用户，最大异常值全是 Manus。Agent 的未来方向是 Proactiveness——主动性才是 agency 的本意：面试完自动把记录填到 Ashby，7×24 小时推理。

07 — 纯血 Agent

「不要把人因为生而为人的限制，颁给 Agent。你应该站在模型的角度去思考问题。」

纯血 Agent 意味着完成任务的方式由智能本身决定——没有人为约束、不模仿人类分工。Workflow 只是规则主导的自动化，不是 Agent。Bitter Lesson 的信仰：用通用方法 + 更大算力，不加人为知识。每增加一个原子能力都必须产生网络效应——加了看图能力后 Agent 自动学会检查网页渲染是否正确。对 MCP 保守：Everything added dilutes everything else。做 Agent 跟训模型很像——更重要的是做对一千件小事，而不是做对三个大事。

08 — 隐忧与终局

「Manus 更大的可能性不是因为竞争而输掉，而是因为失去了独有的价值。」

最大隐忧是失去特色和变得复杂。四点给模型厂商的建议：compression awareness 优于无限扩 context、tool integrated reasoning、异步交互（用户随时插嘴）、error resilience。当前像 2018 年——Transformer 出来了，GPT-3 还没来。Scaling Law 没有停止，但涌现不确定。Agent 已经爆发但每个场景差一口质量。最乐观预期：所有白领获得 7×24 小时 AI 伙伴。「AI 接下来的进步需要用户的参与。」

从猛犸到 Manus，三次创业被技术浪潮淹没，最终做出了那只手——不是因为他比别人更聪明，而是因为他每次都选择重新开始。

通用 Agent · 纯血哲学 · Context Engineering · 长尾价值 · 用户参与——这不是一个 AI 创业故事，而是一部关于放弃、等待和重新出发的个人史。
